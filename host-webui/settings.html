On the LAN

Listening

Each chassis keeps its own Savant UID. Live means we hear it on 192.168.1.0/24. Linked merges both libraries so you can play a remote track on this jack (copy-then-play). Unlink splits the catalogs again: this jack only lists files that live here, and copies pulled from that host are removed. Hosts do not play together.

Playback

This jack

This jack is the TOSLINK output on this chassis. This browser plays on the phone or laptop that opened the page. Only one at a time.

Join the house network so a phone on Wi-Fi can AirPlay to this TOSLINK. Ethernet stays the main address. Passphrase is stored only on this chassis.

AirPlay

Off

Each host advertises its own AirPlay 1 name. iPhone or Mac plays to this TOSLINK. Rename so two boxes never look the same in Control Center.
